AND user_id = ?',</p><p>      [orderId, requestingUserId]  // user_id from JWT claims ALWAYS</p><p>    );</p><p>    // Returns null if order belongs to different user</p><p>    // Controller throws 404 — not 403 (don't reveal existence)</p><p>  }</p><p> </p><p>  Rule: user_id from JWT claims is ALWAYS a query parameter on user-scoped tables.</p><p>  user_id is NEVER accepted from request body or
